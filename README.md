# UTM 坐标工具

纯前端小工具，浏览器本地计算，不上传任何数据。

## 现在能做什么

**经纬度 → UTM**：输入 WGS84 经纬度，得到 UTM 东坐标（Easting/X）、北坐标（Northing/Y）、分区 Zone 和 EPSG 代码。

基于 WGS84 椭球、比例因子 0.9996、假偏移 500,000 m（南半球另加 10,000,000 m），
包含 Norway（32V）与 Svalbard（31X–37X）两个特殊分区规则。

## 注意

- 输入必须是 **WGS84** 经纬度。高德（GCJ-02）、百度（BD-09）的坐标带有偏移，直接换算会有几十到几百米误差，需先纠偏。
- 标准 UTM 适用纬度 80°S – 84°N，超出范围会提示错误。
- EPSG 北半球 `326xx`，南半球 `327xx`，`xx` 为 Zone 编号。
